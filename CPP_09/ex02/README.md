# Ford-Johnson Algorithm
This project implements the **Ford-Johnson algorithm** in c++98. It's an ordenation algorithm that wants to minimize the number of needed comparations, been especially efficient with short and medium sized lists.

---

## 🚀 Usage
Compile the program and then execute it with a list of integers:

```bash
make
```

./PmergeMe 11 2 17 0 16 8 6 15 10 3 21 1 18 9 14 19 12 5 4 20 13 7
